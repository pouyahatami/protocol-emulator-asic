# Implementation specifications

This directory will contain accepted, implementation-facing specifications.

Planned documents:

- `architecture.md` — block boundaries, state, clocks, and reset behavior.
- `isa.md` — instruction encodings, semantics, and exact cycle timing.
- `host-interface.md` — program loading, configuration, FIFO access, and status.
- `pin-interface.md` — mapping, ownership, output-enable, and electrical behavior.

Research proposals are not specifications. A document belongs here only after the corresponding decision is accepted and the behavior can be tested.
